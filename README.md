# نظام إدارة المتاجر

تطبيق عربي لإدارة نقاط البيع والمخزون والصيانة والموظفين والمهام والتقارير على مستوى كل متجر، باستخدام Next.js 16 وSupabase.

## التشغيل المحلي

1. انسخ `.env.example` إلى `.env.local` وأدخل إعدادات Supabase.
2. طبّق مخطط قاعدة البيانات وخطوات الحساب الأول من [دليل إعداد Supabase](SUPABASE_SETUP.md).
3. شغّل التطبيق:

```bash
npm install
npm run dev
```

## الفحوصات

```bash
npm run lint
npm run build
```

البيانات التشغيلية وصلاحيات عزل المتاجر تُقرأ وتُحفظ عبر Supabase مع سياسات RLS؛ لا يعتمد التطبيق على بيانات محلية تجريبية.
